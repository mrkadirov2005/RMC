Superuser action flows

A superuser is a branch admin created by the owner. This index lists only what an admin really gets. Reports, Owner Panel, Centers, Teacher Tasks, Teacher Finance, Settings, Journals, Engineering and KPI entry are owner-only and are not listed. The permission column shows what the page checks; where the sidebar checks something different, both are shown.

Gaps found while mapping

These are not flows. They are problems or missing screens the docs will mention.

  • Permissions only hide thingsThe server checks no permission codes. Dashboard, Archive, Retention, Calendar and Consolidations open for any admin, whatever the owner ticked.
  • Owner-only pages still reachable by addressJournals (/logs) and Engineering (/engineering) have no guard beyond being a superuser, so an admin who types the address can open them. They are not listed as admin flows.
  • Settings gear shows but does not openEvery admin sees the gear, but Settings needs a permission the owner cannot grant, so the admin lands on Unauthorized.
  • No way to change your own passwordAdmins have no screen for it. The owner changes it from the Owner Panel Edit form.
  • Screens with no pageAn older class pop-up with Attendance, Exam Grades and Calendar tabs is never shown, and the teacher profile’s grade dialog has no button that opens it. Exam grades cannot be recorded anywhere.
