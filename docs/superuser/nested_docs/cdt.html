Class detail and lessons

Opening a class shows its Overview, roster, subjects, points, tests and session history in one page.

Open a class and move between its tabs CDT-open-class-tabs

/classes/:classId CRUD_CLASS
  1. From Classes, click a class to open it.
  2. Use the tab bar for Overview, Students, Subjects, Points, Tests and Sessions.

Edit the class from its Overview CDT-edit-class-overview

/classes/:classId CRUD_CLASS
  1. On the class page, click Edit details on the Overview tab.
  2. Change the fields and save without leaving the page.

Edit or archive a student from the class CDT-students-tab-class

/classes/:classId CRUD_CLASS
  1. Open the class and click the Students tab.
  2. Click Edit on a student’s row to update their details, or the delete action to move them to the archive.

Read class points CDT-points-tab

/classes/:classId CRUD_CLASS
  1. Open the class and click the Points tab to see points earned per student.

Open a session from the Sessions tab CDT-open-session

/classes/:classId CRUD_CLASS
  1. Open the class and click the Sessions tab.
  2. Click Open on a session row to enter that lesson’s workflow.

Pick lesson actions and start a lesson CDT-lesson-actions

/classes/:classId CRUD_CLASS
  1. On the class page, click Start.
  2. In the lesson picker, choose which steps to run for this lesson (attendance, homework, activity, points, coins).
  3. Confirm to begin the lesson workflow.

Run a lesson from start to finish CDT-run-lesson

/classes/:classId/sessions/:sessionId/workflow CRUD_CLASS
  1. Start the lesson from the class page, or open an existing session.
  2. On the Attendance tab, mark each student, then click Complete Attendance.
  3. On the Homework tab, use Fill all to set one score for everyone, then adjust individual students, and click through to complete it.
  4. On the Activity tab, do the same for in-class participation.
  5. Mark any student stellar for a bonus, if the lesson earned it.
  6. Continue through the remaining tabs until the workflow shows the lesson as complete.

Fill a score for the whole class at once CDT-fill-all-scores

/classes/:classId CRUD_CLASS
  1. In the lesson workflow’s Homework or Activity tab, click Fill all and choose a score.
  2. Every student gets that score at once — adjust any individual student afterward.

Mark a student as stellar CDT-mark-stellar

/classes/:classId CRUD_CLASS
  1. In the lesson workflow’s scoring tab, click the star toggle next to a student’s name.
  2. That student earns the stellar bonus for the lesson.

Award coins from lesson scores CDT-award-coins

/classes/:classId CRUD_CLASS
  1. While completing the lesson’s Points step, confirm the coin totals shown — they are calculated from the lesson’s scores using the coin-mapping rules set in Settings.

Create a consolidation exercise for a lesson CDT-create-consolidation

/classes/:classId CRUD_CLASS
  1. Inside the lesson workflow, open the Consolidation tab.
  2. Click Add word, type a word, then Add another accepted translation for each accepted spelling of its translation.
  3. Repeat for every word to include, then set the Violation limit (how many lockdown violations a student may have before it is flagged).
  4. Click Create Consolidation Exercise.
Form fields
  • Word
  • Accepted translationsone or more per word
  • Violation limit

Copy or regenerate a consolidation link CDT-copy-consolidation-link

/classes/:classId CRUD_CLASS
  1. On the Consolidation tab, click Copy link to copy the public link for students.
  2. Click Regenerate link to invalidate the old link and create a new one.

Read consolidation results per student CDT-consolidation-results-lesson

/classes/:classId CRUD_CLASS
  1. On the Consolidation tab, scroll to the results list to see each student’s score and any lockdown violations.
