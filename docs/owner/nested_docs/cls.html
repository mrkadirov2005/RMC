Classes

A class (also called a group) is a recurring lesson: one teacher, one subject, one room, one schedule, with students enrolled into it.

Find a class CLS-find-class

/classes CRUD_CLASS
  1. Open Classes from the sidebar.
  2. Type into the search box to narrow the list.

Switch between Groups and By teachers views CLS-groups-view

/classes CRUD_CLASS
  1. On Classes, click Groups for a flat list, or By teachers to see classes grouped under each teacher.

Create a class CLS-create-class

/classes CRUD_CLASS
  1. Open Classes and click Add Class.
  2. Under Group Details, fill in Class Name, Subject, Level and Capacity, and optionally a Class Code, Start Date and End Date.
  3. Choose the Room Number.
  4. Under Class Schedule, set the Start Time and End Time.
  5. Under Payment, set the Payment Amount and Payment Frequency.
  6. Under Assignment, choose the Center (if you are the owner) and the Teacher.
  7. Save — the class is created and ready to have students added.
Form fields
  • Class Name
  • Subject
  • Class Codeoptional
  • Level
  • Capacity
  • Room Number
  • Start Date / End Dateoptional
  • Start Time / End Time
  • Payment Amount
  • Payment Frequency
  • Centerowner only
  • Teacher (Optional)

Edit a class CLS-edit-class-list

/classes CRUD_CLASS
  1. Click the class row’s edit action on Classes.
  2. Change any of the same fields used when creating a class, then save.

Import or export classes CLS-import-export-classes

/classes CRUD_CLASS
  1. Click Export CSV to download the current list.
  2. Use the import control to create classes in bulk from a CSV file.

Generate this month’s sessions CLS-generate-sessions

/classes CRUD_CLASS
  1. On the class’s row in Classes, click the session-generation action.
  2. The month’s lessons are created on the calendar according to the class’s schedule.

Set the lesson length for the next generation CLS-lesson-length-override

/classes CRUD_CLASS
  1. On Classes, open the lesson-length control and set a length in minutes.
  2. This overrides the default only for sessions generated next, from this browser.

Delete a class CLS-delete-class

/classes CRUD_CLASS
  1. Click the class row’s delete action.
  2. Confirm — the class moves to the archive.

Force-delete a class that has attendance CLS-force-delete-class

/classes CRUD_CLASS
  1. Try to delete a class that already has attendance recorded — a warning appears.
  2. Confirm the force-delete option in the warning to remove the class and its attendance together.

Delete several classes at once CLS-bulk-delete-classes

/classes CRUD_CLASS
  1. Tick the checkbox on each class to remove.
  2. Click Delete in the bulk action bar and confirm.
