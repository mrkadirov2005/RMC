Teacher profile

A teacher’s profile groups their information, classes, assignments, tests and payments in one place.

Open a teacher’s profile TPR-open-teacher-profile

/teachers/:teacherId CRUD_TEACHER
  1. From Teachers, click Profile on a row.
  2. Move between the Information, Classes & Students, Assignments, Tests and Payments tabs along the top.

Edit teacher information inline TPR-edit-teacher-inline

/teachers/:teacherId CRUD_TEACHER
  1. On the Information tab, click Edit information.
  2. Change any field and click Save changes — no need to leave the profile.

Update a teacher’s password TPR-update-teacher-password

/teachers/:teacherId CRUD_TEACHER
  1. On the teacher’s profile, click Update Password.
  2. Type a new password, or click Generate, then Copy it before saving.

Manage assignments from the profile TPR-manage-assignments-profile

/teachers/:teacherId CRUD_TEACHER
  1. Open the teacher’s profile and click the Assignments tab.
  2. Click Add Assignment to create one for this teacher’s classes, or click a row to edit or delete it.

Jump to tests from the profile TPR-jump-to-tests

/teachers/:teacherId CRUD_TEACHER
  1. Open the teacher’s profile and click the Tests tab.
  2. Click View All Tests to open the full catalogue, or Create New Test to start a new one for this teacher.

Read a teacher’s payments from the profile TPR-teacher-payments-profile

/teachers/:teacherId CRUD_TEACHER
  1. Open the teacher’s profile and click the Payments tab.
  2. Payments collected for this teacher’s classes are listed here.

Set a teacher’s payment password TPR-set-payment-password

/teachers/:teacherId CRUD_TEACHER
  1. On the teacher’s profile, find Set Payment Password.
  2. Type a password or click Generate, then Copy it, and save.

Known issueThe teacher payment sign-in screen is not shown anywhere in the app yet, so this password cannot currently be used to sign in.
