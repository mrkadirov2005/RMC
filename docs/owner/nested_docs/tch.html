Teachers

The Teachers page lists every teacher, with tabs for KPI scores and statistics alongside the roster.

Find a teacher TCH-find-teacher

/teachers CRUD_TEACHER
  1. Open Teachers from the sidebar.
  2. Type into the search box to narrow the list, then click Clear to reset it.

Add a teacher TCH-add-teacher

/teachers CRUD_TEACHER
  1. Open Teachers and click Add Teacher (or similar button above the list).
  2. Fill in First Name, Last Name, Employee ID, Email, Phone, Date of Birth, Qualification, Specialization, Teacher Share (%), Gender and Status.
  3. If you are the owner, also choose the Center.
  4. Set the initial Username and Password.
  5. Save — the teacher can now sign in at the teacher login page.
Form fields
  • First Name / Last Name
  • Employee ID
  • Email
  • Phone
  • Date of Birth
  • Qualification
  • Specialization
  • Teacher Share (%)the teacher’s cut of class payments
  • Gender
  • Status
  • Username / Password

Edit a teacher TCH-edit-teacher

/teachers CRUD_TEACHER
  1. Click the teacher’s row action Edit on the Teachers list.
  2. Update any of the same fields used when adding a teacher, then save.

Import or export teachers TCH-import-export-teachers

/teachers CRUD_TEACHER
  1. Click Export CSV to download the current list.
  2. Click the import icon and choose a CSV file to create teachers in bulk.

Delete a teacher TCH-delete-teacher

/teachers CRUD_TEACHER
  1. Click the teacher’s row action Delete.
  2. Confirm — the teacher moves to the archive.

Delete several teachers at once TCH-bulk-delete-teachers

/teachers CRUD_TEACHER
  1. Tick the checkbox on each teacher to remove.
  2. Click Delete in the bulk action bar and confirm.

Read the KPI overview TCH-kpi-overview

/teachers CRUD_TEACHER
  1. Open Teachers and click the KPI tab.
  2. Every teacher’s current KPI score is listed here.

Search the KPI overview TCH-search-kpi

/teachers CRUD_TEACHER
  1. On the KPI tab, type into the search box to narrow the list to matching teachers.

Record a teacher’s KPI TCH-record-kpi

/teachers OWNER_ONLY
  1. From the Teachers → KPI tab, or the teacher’s own KPI history page, click Add (or Edit) for the month.
  2. Enter Contribution (0–100), Teaching Quality (0–100) and optional Notes.
  3. Save — this becomes that teacher’s KPI score for the period.
Form fields
  • Contribution (0–100)
  • Teaching Quality (0–100)
  • Notesoptional

Open a teacher’s KPI history TCH-kpi-history

/teachers CRUD_TEACHER
  1. From Teachers → KPI tab, click a teacher’s row.
  2. Every past month’s KPI score for that teacher is listed.

Read teacher statistics TCH-teacher-statistics

/teachers CRUD_TEACHER
  1. Open Teachers and click the Statistics tab.
