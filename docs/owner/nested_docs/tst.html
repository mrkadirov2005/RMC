Tests

Tests are built with a four-step wizard — Basic Info, Add Questions, Settings, Review — then assigned to students.

Read test statistics TST-test-statistics

/tests MANAGE_TESTS
  1. Open Tests and stay on the Overview tab.
  2. Review totals, the breakdown by test type, and the teacher leaderboard.

Browse and filter the test catalogue TST-test-catalogue

/tests MANAGE_TESTS
  1. Open Tests and click the Catalogue tab.
  2. Use the search box and the type and status filters to narrow the list.

Create a test TST-create-test

/tests MANAGE_TESTS
  1. Click Create Test (from Tests, or from a teacher profile’s Tests tab).
  2. Step 1 — Basic Info: enter Test Name, Test Type, Subject, Description, Instructions, Duration and Passing Marks. Owners also choose a Center.
  3. Step 2 — Add Questions: click Add Passage for a reading passage (Title, Difficulty, Passage Content), and Add Question for each question — set the Question Text, Question Type, Marks, and its Options if it is multiple choice. Set a Word Limit and Grading Rubric for written answers, or the accepted Correct Answer(s) and an Explanation for auto-graded ones.
  4. Step 3 — Settings: tick Timed Test, Shuffle Questions, Show Results Immediately, Private test and Allow Retakes as needed — if retakes are allowed, set Maximum Retakes. Choose Assign To: All Students, Specific Students, Specific Class, or Specific Teacher’s Students.
  5. Step 4 — Review: check the summary, then click Create to save the test.
Form fields
  • Test Name / Test Type / Subject
  • Description / Instructions
  • Duration (minutes) / Passing Marks
  • Question Text / Question Type / Marks / Options
  • Word Limit / Grading Rubricwritten answers
  • Correct Answer(s) / Explanationauto-graded answers
  • Timed Test / Shuffle Questions / Show Results Immediately / Private test / Allow Retakescheckboxes
  • Assign ToAll Students / Specific Students / Specific Class / Specific Teacher’s Students

A private test is only visible to its creator, and to that teacher’s own students if a teacher created it.

Open a test TST-open-test

/tests MANAGE_TESTS
  1. Click a test in the catalogue.
  2. Its questions, settings and submissions are shown together on one page.

Edit a test TST-edit-test

/tests MANAGE_TESTS
  1. Open the test and click Edit.
  2. The same wizard opens pre-filled — change any step and save.

A teacher can only edit tests they created themselves; the owner and admins can edit any test.

Assign a test to classes or students TST-assign-test

/tests MANAGE_TESTS
  1. Open the test and click Assign.
  2. Choose the Assignment Type, then pick the classes or students under Select Classes / Select Students.
  3. Set the Due Date and tick Mandatory if it must be completed.
  4. Save — the test now appears in each assigned student’s test list.
Form fields
  • Assignment Type
  • Due Date
  • Mandatory

Create, copy, replace or turn off a share link TST-share-link

/tests MANAGE_TESTS
  1. Open the test and find the Share link panel.
  2. Click Create share link to mint one, or Copy to copy an existing one.
  3. Click Replace link to invalidate the old link and create a new one.
  4. Click Turn off to disable sharing entirely.

Only students the test is assigned to can start it from the link; anyone else sees “not assigned”.

Review a submission TST-review-submission

/tests MANAGE_TESTS
  1. From a test’s submissions list, click a student’s attempt.
  2. Their answers and score are shown question by question.

Grade a submission TST-grade-submission

/tests MANAGE_TESTS
  1. Open a submission that has written answers awaiting grading.
  2. For each answer, enter the marks and optionally Add feedback for this answer.
  3. Save — the student’s final score updates.

Delete a test TST-delete-test

/tests MANAGE_TESTS
  1. Open the test’s row menu on the catalogue and choose Delete.
  2. Confirm — the test is removed.
