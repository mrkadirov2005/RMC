Owner Panel: Admins tab

The Admins tab manages branch admin (superuser) accounts and what they can see.

Add a branch admin ADM-add-admin

/owner/manage
  1. Open Owner Panel and click the Admins tab.
  2. Click Add.
  3. Choose the Branch, and fill in Username, Email, Password, First Name, Last Name, Role and Status.
  4. Save — the admin can now sign in at the admin login page, but sees nothing until permissions are granted.
Form fields
  • Branch
  • Username
  • Email
  • Password
  • First Name / Last Name
  • Role
  • Status

Choose what an admin can see and do ADM-choose-admin-permissions

/owner/manage
  1. Open the admin’s row and find the permissions checklist.
  2. Tick each page they should be able to open — Dashboard, Students, Telegram Leads, Archive, Retention, Teachers, Classes, Rooms, Calendar, Tests, Payments, Salary, Assignments, Subjects and Debts.
  3. Save — the admin’s sidebar updates to match.

Known issueTeacher Tasks, Finance and Settings are not in this checklist yet, so they cannot be granted to an admin at all.

Edit an admin ADM-edit-admin

/owner/manage
  1. Click the admin’s row edit action.
  2. Update any field and save.

Change an admin’s password ADM-change-admin-password

/owner/manage
  1. Open the admin’s Edit form.
  2. Type a new password into the Password field, or leave it blank to keep the current one.
  3. Save.

Delete an admin ADM-delete-admin

/owner/manage
  1. Click the admin’s row delete action and confirm.
  2. They can no longer sign in.
