Engineering and journals

Engineering and Journals are technical pages for diagnosing problems. They are only linked from Settings.

Open Engineering and Journals from Settings ENG-open-engineering-from-settings

/engineering
  1. Open Settings and click the Journals or Engineering card to open the page with no sidebar entry of its own.

Check server and database health ENG-server-database-health

/engineering
  1. Open Engineering and stay on the Server tab.
  2. Use the refresh interval control or click Refresh to update the figures manually.

Browse the database schema by domain ENG-database-schema

/engineering
  1. Open Engineering → Database tab.
  2. Click a domain in the list to see its tables and columns.

Browse and edit database rows ENG-studio-browse-edit

/engineering Owner only on the server
  1. Open Engineering → Studio tab.
  2. Use Find table… to pick a table, then Search rows… to find a row.
  3. Click a row’s edit action to open the editor, change values, and click Save row.

Add a database row ENG-studio-add-row

/engineering
  1. On the Studio tab, click Add row.
  2. Fill in the fields for the table and click Save row.

Delete a database row ENG-studio-delete-row

/engineering
  1. On the Studio tab, click a row’s delete action and confirm.

Review warnings ENG-review-warnings

/engineering
  1. Open Engineering → Warnings tab to see recent warning events.

Review failed requests ENG-review-failed-requests

/engineering
  1. Open Engineering → Failed Requests tab, and click Refresh to reload it.

Read the logging reference ENG-logging-reference

/engineering
  1. Open Engineering → Logging tab — this is an information page with no controls.

Read the operations reference ENG-operations-reference

/engineering
  1. Open Engineering → Operations tab — this is an information page with no controls.

Search the request journal ENG-search-journal

/engineering
  1. Open Logs (linked from Settings).
  2. Type a search term, click Filters for more options, and Clear filters to reset.

List accounts seen in the loaded logs ENG-list-accounts-logs

/engineering
  1. On Logs, the accounts that appear in the rows currently on screen are listed.

This is not a live list of who is currently signed in — it only reflects the log rows loaded on screen.
