Gaps found while mapping

These are not flows. They are problems or missing screens the docs will mention.

  • Owner Panel is missing tabsOnly Admins and Owners exist. Branches, teachers, students, finance and analytics are managed elsewhere, and their unused panel components are never shown.
  • Redeploy and data reset are unreachableThe screens for “Redeploy server” and “Dev data reset” exist in the code, but no page shows them. The server routes exist too.
  • Three permissions cannot be grantedTeacher Tasks, Finance and Settings are missing from the admin permission picker, so only the owner reaches them.
  • No self-service password reset“Forgot password?” only shows a contact message. Another owner changes the password from the Edit form.
  • Server-side permissions are not checkedPermission codes only hide pages and buttons. The server does not check them on any route.
