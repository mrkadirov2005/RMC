My tests

My Tests lists the tests a teacher has written, with a full test builder reachable from here.

Browse my tests TST-browse-my-tests

/teacher-portal, My Tests tab
  1. Open Teacher Portal → My Tests.
  2. Every test you wrote is listed, with question, submission and to-grade counts.

Filter tests by owner, status and type TST-filter-my-tests

/teacher-portal, My Tests tab
  1. Use the filter bar to switch between “mine” and all tests, or show only tests awaiting grading.

Create a test TST-create-test-teacher

/tests/create
  1. Click Create Test.
  2. Follow the four-step wizard: Basic Info, Add Questions, Settings, Review.

Open a test TST-open-test-teacher

/teacher-portal, My Tests tab
  1. Click a test in My Tests — its details open inside the portal.

Edit a test I wrote TST-edit-my-test

/tests/:testId/edit
  1. Open the test and click Edit.
  2. Change any step of the wizard and save.

You can only edit tests you created yourself — other teachers’ tests have no Edit option for you.

Delete a test I wrote TST-delete-my-test

/teacher-portal, My Tests tab
  1. Open the test’s menu on My Tests and choose Delete, then confirm.

Assign a test to classes or students TST-assign-test-teacher

/tests/:testId/assign
  1. Open the test and click Assign.
  2. Choose the Assignment Type, pick classes or students, set the Due Date and Mandatory flag, then save.

Create, copy, replace or turn off a share link TST-share-link-teacher

/teacher-portal, My Tests tab
  1. Open the test and use the Share link panel: Create share link, Copy, Replace link, or Turn off.

Review submissions TST-review-submissions-teacher

/tests/submissions/:submissionId
  1. From the test page, click a student’s submission to see their answers and score.

Grade a submission TST-grade-submission-teacher

/tests/submissions/:submissionId/grade
  1. Open a submission awaiting grading.
  2. Enter marks and optional feedback for each answer, then save.
