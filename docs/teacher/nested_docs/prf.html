Profile, salary and payments

The Profile tab holds a teacher’s own password and salary information.

Change my password PRF-change-my-password

/teacher-portal, Profile tab
  1. Open Teacher Portal → Profile.
  2. Fill in Current password, New password and Confirm new password.
  3. Save — use the new password next time you sign in.
Form fields
  • Current password
  • New password
  • Confirm new password

Read my salary PRF-read-my-salary

/teacher-portal, Profile tab
  1. On the Profile tab, open the salary section to see what you have earned and been paid.

Switch the salary view between stats and details PRF-switch-salary-view

/teacher-portal, Profile tab
  1. Click View Details to see individual payouts, or Back to Statistics to return to the summary view.
  2. Filter by Paid or Unpaid.

Open Payments with the payment password PRF-open-payments-teacher

/payments
  1. Go to /payments.
