Tasks from the administration

Tasks the owner assigns to a teacher are responded to here.

Accept a task TSK-accept-task

/teacher-portal, Tasks tab
  1. Open Teacher Portal → Tasks.
  2. Click Accept on a task.

Reject a task TSK-reject-task

/teacher-portal, Tasks tab
  1. Click Reject on a task.

Mark a task done TSK-mark-task-done

/teacher-portal, Tasks tab
  1. Click Mark Done on a task once it is finished.
