Gaps found while mapping

These are not flows. They are problems or missing screens the docs will mention.

  • No language or theme switchThe portal header that had the UZ/EN switch is never shown, and the hidden sidebar removes the theme button.
  • Attendance only inside a lessonThe Attendance tab is read-only. Attendance is taken from the lesson workflow.
  • No self-service password reset“Forgot password?” only shows a contact message.
